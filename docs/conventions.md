We are following the modular monolithic architecture, where we have divided the features according to modules and then each module has its own related data. Module to module communicaiton is done through the service files for each module by calling the function in the service file.
All the routers for the apis are in a single file i.e routes.ts in the routes folder, this has all the stuff which is related to the routes. So we are importing the router which will be exported from the *.route.js file for each feature module. So we will have all the routers in one place, and then we will be with the helps of these routers, register all the routes in each router to the express instance that we have created
